Command-Line Interface for nepephemeral 2
=========================================

This is a simple command-line interface for nepephemeral 2.

This utility should be run on a separate and trusted terminal / xterm session.

Building
--------

This utility requires cmake, nepe2-base, rcpr, minunit, libcrypto (OpenSSL or
LibreSSL), and XCB. It uses pkgconfig to find required libraries.
